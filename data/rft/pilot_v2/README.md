# Natural-CoT v2 balanced RFT pilot

`train.jsonl` is a deterministic subset of
`data/rft/derived_v3_fewshot/train.jsonl`, generated by
`scripts/sample_rft_pilot.py` with seed 2026.

For each ToM order 1, 2, and 3, it selects 50 complete counterfactual pairs and
keeps both the observed and hidden rows. The result contains 300 prompts and
150 pairs, with exactly 50 rows in each `order x intervention` bucket. Sampling
16 candidates per prompt produces 4,800 candidate trajectories.

The selected rows are unchanged copies of the v2 source records. See
`manifest.json` for source/output hashes and selected pair IDs.
